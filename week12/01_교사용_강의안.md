# 12주차 교사용 강의안 — 종합 실습 (미니게임 스스로 완성)

## 학습 목표
- 12주 동안 배운 개념(순차, 반복, 조건, 변수, 연산자, 리스트, 신호, 나만의 블록)을 종합적으로 활용한다.
- 스스로 아이디어를 정하고, 계획하고, 구현하고, 테스트하는 전 과정을 경험한다.
- 자신의 실력 향상을 스스로 점검한다.

## 준비물
- 학생 1인당 컴퓨터/노트북 1대, 스크래치 접속
- 학생용 실습지의 "프로젝트 아이디어 카드" (방향을 못 정하는 학생용)

## 시간 배분 (총 60분)

| 시간 | 활동 |
|---|---|
| 0~5분 | 도입: 오늘은 새로운 개념 없이, 지금까지 배운 것만으로 나만의 게임 만들기 |
| 5~10분 | 프로젝트 주제 정하기 (아이디어 카드 참고 가능) |
| 10~50분 | 제작 시간 (교사는 순회하며 막힌 부분 코칭) |
| 50~57분 | 짝과 서로 플레이해보고 피드백 주고받기 |
| 57~60분 | 자기평가 작성, 12주 과정 마무리 |

## 진행 방식

이번 주는 새로운 개념을 가르치지 않고, **교사는 코치 역할**을 합니다. 학생이 막히면 답을 바로 주지 말고 "지금까지 배운 것 중 뭘 쓰면 될까?"라고 되물어 스스로 떠올리도록 유도하세요.

아이디어가 없는 학생에게는 실습지의 "프로젝트 아이디어 카드" 3가지 중 하나를 골라 시작하게 하고, 이미 아이디어가 있는 학생은 자유롭게 진행하도록 합니다.

## 코칭 시 활용할 수 있는 질문

- "지금 화면에 점수나 생명을 보여주고 싶으면 뭘 만들어야 했지?" → 변수
- "같은 동작을 여러 번 반복해야 하면?" → 반복문
- "특정 상황에서만 다르게 행동하게 하려면?" → 조건문
- "여러 캐릭터가 순서대로 움직여야 하면?" → 신호
- "코드가 너무 길고 반복되면?" → 나만의 블록

## 자주 발생하는 상황 & 대응 팁

| 상황 | 대응 팁 |
|---|---|
| 너무 욕심을 내서 완성을 못함 | "일단 가장 기본적인 것부터 동작하게 만들고, 시간이 남으면 추가하자"고 범위 조정 유도 |
| 아이디어가 안 떠오름 | 아이디어 카드 제시, 또는 지난 주차 프로젝트 중 하나를 발전시키도록 제안 |
| 특정 기능 구현에 막힘 | 관련 주차 자료(강의안/실습지)를 다시 펼쳐보게 안내 |
| 시간이 부족함 | 완성이 목표가 아니라 "배운 것을 스스로 써보는 경험"이 목표임을 강조 |

## 마무리
12주 과정을 마치며 학생들에게 "처음엔 방향키로 캐릭터 하나 움직이는 것도 어려웠는데, 지금은 스스로 게임을 만들 수 있게 되었다"는 성장을 짚어주는 것이 중요합니다.
