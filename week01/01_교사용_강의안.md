# 1주차 교사용 강의안 — 화면 구성, 좌표, 움직이기 블록

> 💡 실제 수업 진행은 `04_슬라이드.html`만 보고 할 수 있습니다. 각 장표 하단에 발표자 노트(실제 멘트)가 포함되어 있어요 (N 키로 노트 패널 켜기/끄기). 이 강의안은 사전 준비와 배경 설명, 세부 팁을 위한 참고 문서입니다.

## 학습 목표
- 코드(코딩)가 "컴퓨터가 알아듣는 정확한 명령"이라는 것을 이해한다.
- 스크래치 화면 구성 요소(무대, 스프라이트 목록, 블록 팔레트, 스크립트 영역)를 안다.
- x, y 좌표가 캐릭터의 위치를 나타낸다는 것을 이해한다.
- `~(으)로 이동하기`(절대 위치)와 `~만큼 바꾸기`(상대 변화)의 차이를 구분한다.
- 이벤트 블록과 움직임 블록을 결합해, 방향키로 캐릭터를 움직일 수 있다.
- 블록 삭제, 실행 취소(Ctrl+Z) 등 에디터 기본 조작을 할 수 있다.
- 프로젝트를 저장하고 다음 주에 이어서 작업할 수 있다.

## 도입: 로봇 조종 게임 — 온라인 버전 (0~3분)
- 슬라이드(`04_슬라이드.html`) 3번 장표에 있는 "로봇 조종판"을 화면 공유합니다. 격자 위에 로봇 이모지가 있고, `앞으로 한 칸` / `왼쪽으로 돌기` / `오른쪽으로 돌기` / `처음으로` 버튼으로 교사가 직접 조작할 수 있습니다.
- 학생들에게 "로봇을 목표 칸까지 보내려면 어떤 명령을 순서대로 줘야 할까?"라고 묻고, 음소거를 해제하거나 채팅으로 명령을 외치게 합니다.
- 교사는 학생들이 외친 명령을 **들은 순서 그대로만** 버튼을 눌러 실행합니다. 화면 아래 실행 기록에 명령이 순서대로 쌓이는 것을 함께 보여주세요.
- 한 번은 일부러 순서를 하나 바꿔서 눌러보고, 로봇이 목표에서 벗어나는 것을 보여줍니다.
- 마무리 한마디: "컴퓨터(스크래치 캐릭터)도 이 로봇처럼, 우리가 정확하고 순서대로 내린 명령만 그대로 실행해요. 이렇게 컴퓨터가 알아듣는 정확한 명령을 무엇이라고 하는지, 잠시 후에 알아볼게요."
- 시간이 부족하면 교사 혼자 버튼을 눌러 시연만 보여줘도 됩니다(선택 활동).

## 환경 설정 확인 (3~10분)

**환경 설정**
- 권장 브라우저: 크롬(Chrome) 최신 버전. 크롬이 없으면 엣지(Edge)도 가능.
- 한국어 설정: 화면 좌측 상단의 지구본 모양 아이콘 클릭 → "한국어" 선택.

**계정 만들기와 저장하기**
- 스크래치는 로그인 없이도 실습은 가능하지만, **저장하려면 계정이 필요**합니다.
- 방법 A (권장): 교사가 학급/학생별 계정을 사전에 일괄 생성해 아이디·비밀번호 카드로 배부합니다. 교사 이메일로 일괄 가입하면 학생 개인정보 노출을 최소화할 수 있습니다.
- 방법 B: 학생이 직접 가입할 경우, 사용자 이름에 실명이나 개인정보를 넣지 않도록 지도합니다(예: 별명 + 숫자 조합).
- 저장 방법 두 가지:
  - 로그인한 경우: 상단 메뉴 `파일 > 저장하기`
  - 로그인 없이도: 상단 메뉴 `파일 > 컴퓨터에 저장하기` (.sb3 파일로 저장됨)
- 파일명 규칙을 통일하세요: `6-2_이름_1주차` 형태로 저장하면 다음 주에 불러오기 쉽습니다.
- 이번 시간이 끝날 때 반드시 저장하는 습관을 들이도록, 정리 시간에 한 번 더 확인합니다.

## 핵심 개념 설명 (10~28분)

**0) 코딩이란? — 코드는 컴퓨터가 이해하는 언어**
- 사람끼리는 말이 조금 애매해도(예: "저기 있는 거 좀 줘") 서로 알아듣지만, 컴퓨터는 정확하고 정해진 방식으로 말해주지 않으면 전혀 알아듣지 못합니다.
- 방금 로봇 조종 게임에서 "앞으로 한 칸"처럼 정확하게, 순서대로 명령해야 알아들었던 것처럼, 컴퓨터에게도 정확한 방식으로 명령을 내려야 합니다. 이렇게 **컴퓨터가 알아듣는 정확한 명령을 "코드(code)"**라고 부릅니다.
- 원래 코드는 영어와 기호로 이루어진 글자로 입력합니다(예: 파이썬, 자바 같은 프로그래밍 언어). 스크래치는 그 글자 코드를 직접 타이핑하지 않고, **블록을 끼워 맞추는 것만으로 컴퓨터에게 똑같이 명령을 내릴 수 있게** 만든 도구입니다.
- 정리: 오늘 우리가 블록을 조립하는 것도 "코딩"이고, 컴퓨터는 그 블록들을 보고 정확히 그대로 실행합니다.
- **"스크래치는 진짜 코딩이 아니지 않나요?"에 대한 답변**: 슬라이드에서 파이썬 코드 한 줄(`x = x + 10`)과 스크래치 블록(`x좌표를 10만큼 바꾸기`)을 나란히 보여주며, "적는 방법(글자 vs 블록)만 다를 뿐 컴퓨터에게 명령을 내리는 원리는 완전히 같다"고 짚어줍니다.
- **동기부여: 코딩은 어디에 쓰일까?** 게임(마인크래프트, 로블록스), 앱(유튜브, 카카오톡), 로봇(청소기 로봇, 자율주행차), AI(챗봇, 번역기)가 모두 코드로 만들어진다는 것을 슬라이드로 짚어주고, "오늘 배우는 것이 이 모든 것의 첫걸음"이라고 마무리합니다. "오늘 이걸 만들 거예요"처럼 과한 기대보다는 앞으로의 여정을 보여주는 톤을 유지하세요.

**1) 화면 구성 소개**
- 무대(Stage): 오른쪽 위, 실제 프로그램이 실행되는 화면
- 스프라이트 목록: 오른쪽 아래, 등장인물(캐릭터) 목록
- 블록 팔레트: 왼쪽, 사용 가능한 블록들이 카테고리별로 모여있는 곳 (동작/형태/소리/이벤트/제어/…)
- 스크립트 영역: 가운데, 블록을 끌어다 놓고 조립하는 공간

> 비유: "블록 팔레트는 재료 창고, 스크립트 영역은 요리하는 도마"라고 설명하면 이해가 빠릅니다.

**2) 좌표 개념**
- 무대는 가로 -240 ~ 240, 세로 -180 ~ 180 범위를 가진다.
- 가운데가 (0, 0)이고, 오른쪽으로 갈수록 x가 커지고, 위로 갈수록 y가 커진다.
- ⚠️ 학생들이 자주 헷갈리는 부분: "위로 갈수록 y가 커진다"는 것 (수학 그래프와 같은 방향이라 안내하면 도움됨)

**좌표 체험 활동**
- 배경 고르기에서 "Xy-grid" 배경을 추가해 격자를 보며 좌표 감을 잡게 합니다.
- 스프라이트를 마우스로 직접 끌어보면서, 오른쪽 스프라이트 정보 패널의 x, y 숫자가 실시간으로 바뀌는 것을 관찰하게 합니다.
- 게임: 교사가 "x 100, y 50으로 가보세요!"라고 외치면 학생들이 각자 마우스로 캐릭터를 끌어 맞춰보고, 화면 공유나 채팅으로 결과를 보여주며 확인합니다. (소회의실 기능을 쓸 수 있다면 2인 1조로 서로 확인해도 좋습니다.)

**3) 움직임 블록: 이동하기 vs 바꾸기**
- "동작" 카테고리에서 `x: 0 y: 0(으)로 이동하기`와 `x좌표를 (10)만큼 바꾸기` 두 블록을 나란히 보여줍니다.
- 차이 설명: **"이동하기"는 순간이동(정해진 자리로 딱 이동)**, **"바꾸기"는 그만큼 더하기(지금 위치에서 상대적으로 이동)**.
- 짧은 실험: 두 블록을 여러 번 눌러보며 "이동하기"는 몇 번을 눌러도 같은 자리에 멈추고, "바꾸기"는 누를 때마다 계속 이동한다는 것을 직접 확인시킵니다.
- 참고(3주차 예고): "동작" 카테고리에는 `10걸음 움직이기`, `90도 돌기`처럼 방향을 기준으로 움직이는 블록도 있습니다. 오늘은 이름만 살짝 보여주고, 자세한 사용은 3주차 반복문 시간에 다룹니다.
- "이벤트" 카테고리에서 `초록 깃발을 클릭했을 때`, `스페이스 키를 눌렀을 때` 블록 소개 → 키 종류는 클릭해서 바꿀 수 있음(화살표 키로 변경)

**4) 에디터 기초 조작**
- 블록 삭제: 블록을 왼쪽 블록 팔레트 쪽으로 다시 끌어다 놓으면 삭제됩니다.
- 실행 취소: `Ctrl+Z`로 되돌리기, `Ctrl+Shift+Z`(또는 `Ctrl+Y`)로 다시 실행.
- 블록 복제: 블록을 우클릭 → "복사하기". 이때 그 블록 아래에 연결된 블록들도 함께 복사되니 주의.
- 스프라이트가 무대 밖으로 사라졌을 때: 스프라이트 정보 패널에서 x, y 값을 직접 0, 0으로 입력해 되돌립니다.

## 함께 실습 (28~50분) — 교사 진행 순서

1. 새 프로젝트 만들기 → 기본 고양이 스프라이트 확인
2. `이벤트` 카테고리에서 `초록 깃발을 클릭했을 때` 블록을 스크립트 영역에 놓기
3. `동작` 카테고리에서 `x: 0 y: 0(으)로 이동하기` 블록을 아래에 연결 (시작 위치 초기화)
4. 새로운 스크립트 4개 추가:
   - `위쪽 화살표 키를 눌렀을 때` → `y좌표를 10만큼 바꾸기`
   - `아래쪽 화살표 키를 눌렀을 때` → `y좌표를 -10만큼 바꾸기`
   - `오른쪽 화살표 키를 눌렀을 때` → `x좌표를 10만큼 바꾸기`
   - `왼쪽 화살표 키를 눌렀을 때` → `x좌표를 -10만큼 바꾸기`
5. 초록 깃발을 눌러 실행 → 방향키로 캐릭터가 움직이는지 확인
6. `파일 > 컴퓨터에 저장하기` (또는 로그인했다면 `저장하기`)로 오늘 작업물을 `6-2_이름_1주차` 형식으로 저장

## 스스로 해보기 (50~57분) — 차등 목표
- **필수 (모든 학생)**: 방향키 4개로 캐릭터가 사방으로 움직이는 것을 완성하고 저장까지 마치기
- **도전 과제**: 이동 속도를 더 빠르게 만들기(숫자를 10보다 크게), 캐릭터를 하나 더 추가해서 똑같이 움직이게 만들기
- **확장 과제 (빠르게 끝낸 학생)**: 배경 바꾸기, 스프라이트 크기 바꾸기, 벽에 닿았을 때 시작 위치(0, 0)로 되돌아가는 스크립트 추가해보기
- **플랜 B (시간이 부족한 경우)**: 방향키 2개(예: 상하 또는 좌우)만 완성해도 괜찮습니다. 단, 저장은 꼭 하도록 안내

## 자주 발생하는 오류 & 대응 팁

| 상황 | 원인 | 해결 팁 |
|---|---|---|
| 캐릭터가 안 움직임 | 이벤트 블록 없이 동작 블록만 있음 | "블록은 반드시 이벤트 블록 아래에 연결되어야 실행된다"고 다시 설명 |
| 방향이 반대로 움직임 | +/- 값을 반대로 넣음 | 좌표 개념(오른쪽=+x, 위=+y) 다시 짚어주기 |
| 블록이 서로 안 붙음 | 블록 색깔/모양이 다른 카테고리라 착각 | 블록은 퍼즐처럼 딱 맞을 때만 "딸깍" 소리와 함께 붙는다고 안내 |
| 여러 스크립트가 뒤섞임 | 스크립트 영역 정리 안 됨 | 스크립트를 마우스로 드래그해 위치 정돈하는 법 알려주기 |
| 블록을 잘못 놓아 지우고 싶어함 | 삭제 방법을 모름 | 블록을 팔레트 쪽으로 끌어다 놓으면 삭제된다고 안내 |
| 실수로 잘못 만들어서 되돌리고 싶어함 | 실행 취소 단축키를 모름 | `Ctrl+Z`로 되돌릴 수 있다고 안내 |
| 스프라이트가 무대 밖으로 사라짐 | 좌표값이 범위(-240~240, -180~180)를 벗어남 | 정보 패널에서 x, y를 0, 0으로 직접 입력하게 안내 |
| 저장을 안 하고 꺼서 작업이 사라짐 | 저장 습관이 없음 | 매 시간 끝에 저장하는 루틴을 강조하고, 파일명 규칙을 다시 확인 |
