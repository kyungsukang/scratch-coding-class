# 1주차 실습지 — 방향키로 캐릭터 움직이기

이름: ______________

## 오늘의 미션
방향키(↑ ↓ ← →)를 누르면 고양이가 화면 위에서 움직이도록 만들어봅시다!

## 코딩이란 무엇일까요?
사람끼리는 말이 조금 애매해도 서로 알아듣지만, 컴퓨터는 정확하게 말해주지 않으면 전혀 알아듣지 못해요. 이렇게 **컴퓨터가 알아듣는 정확한 명령을 "코드(code)"**라고 부르고, 코드를 만드는 것을 "코딩"이라고 해요. 스크래치는 이 코드를 글자로 직접 타이핑하지 않고, 블록을 끼워 맞추는 것만으로 컴퓨터에게 명령을 내릴 수 있게 해주는 도구예요.

## 준비하기
1. 인터넷 주소창에 https://scratch.mit.edu/projects/editor/ 를 입력해서 접속하세요.
2. 화면 왼쪽 상단의 지구본 아이콘을 눌러 "한국어"로 설정하세요.
3. 선생님이 알려준 방법으로 로그인하세요. (계정이 있어야 나중에 저장할 수 있어요!)
4. 화면 오른쪽 위에 고양이 캐릭터가 보이면 준비 완료!

## 화면 살펴보기
아래 빈칸에 각 영역의 이름을 적어보세요. (선생님이 알려준 내용을 떠올려보세요)

- 오른쪽 위, 캐릭터가 실제로 움직이는 화면: __________
- 오른쪽 아래, 캐릭터 목록이 있는 곳: __________
- 왼쪽, 블록들이 모여있는 곳: __________
- 가운데, 블록을 조립하는 곳: __________

## 좌표 감 잡기 (실습 전 워밍업)
1. 배경 고르기 버튼을 눌러 "Xy-grid" 배경을 무대에 추가해보세요.
2. 고양이를 마우스로 이리저리 끌어보면서, 오른쪽 스프라이트 정보 패널에 있는 x, y 숫자가 어떻게 바뀌는지 살펴보세요.
3. 짝과 함께: 한 명이 "x 100, y 50으로 가봐!"라고 외치면, 다른 한 명이 마우스로 고양이를 끌어서 맞춰보세요.

## 단계별로 따라하기

**1단계. 시작 위치 정하기**
- 왼쪽 블록 팔레트에서 `이벤트` 카테고리를 클릭하세요.
- `초록 깃발을 클릭했을 때` 블록을 스크립트 영역(가운데)으로 끌어다 놓으세요.
- `동작` 카테고리를 클릭하고, `x: 0 y: 0 (으)로 이동하기` 블록을 찾아서 방금 놓은 블록 아래에 딱 붙여보세요.

> 💡 잠깐! `~(으)로 이동하기`는 그 자리로 "순간이동"하는 블록이고, 뒤에서 배울 `~만큼 바꾸기`는 지금 위치에서 "그만큼 더 움직이는" 블록이에요. 서로 다르니 헷갈리지 마세요!

**2단계. 위쪽 화살표로 위로 움직이기**
- `이벤트` 카테고리에서 `스페이스 키를 눌렀을 때` 블록을 새로 끌어다 놓으세요.
- 블록 안의 "스페이스"라고 써진 부분을 클릭해서 "위쪽 화살표"로 바꾸세요.
- `동작` 카테고리에서 `y좌표를 10만큼 바꾸기` 블록을 그 아래에 연결하세요.

**3단계. 나머지 방향도 만들기**
아래 표를 보고 2단계와 똑같은 방법으로 3개를 더 만드세요.

| 키 | 연결할 블록 |
|---|---|
| 아래쪽 화살표 | y좌표를 **-10**만큼 바꾸기 |
| 오른쪽 화살표 | x좌표를 **10**만큼 바꾸기 |
| 왼쪽 화살표 | x좌표를 **-10**만큼 바꾸기 |

**4단계. 실행해보기**
- 무대 위쪽의 초록 깃발(▶)을 클릭하세요.
- 키보드 방향키를 눌러서 고양이가 사방으로 움직이는지 확인하세요.

**5단계. 저장하기**
- 화면 위쪽 메뉴에서 `파일`을 클릭하세요.
- 로그인했다면 `저장하기`를, 로그인이 어렵다면 `컴퓨터에 저장하기`를 선택하세요.
- 파일 이름은 선생님이 알려준 규칙(예: `6-2_이름_1주차`)대로 저장하세요.

## 에디터 사용법 미니 팁
- 블록을 지우고 싶으면: 블록을 왼쪽 블록 팔레트 쪽으로 끌어다 놓으면 사라져요.
- 실수했으면: 키보드에서 `Ctrl + Z`를 누르면 방금 한 일을 되돌릴 수 있어요.
- 고양이가 무대 밖으로 사라졌으면: 스프라이트 정보 패널에서 x, y 칸에 직접 0, 0을 입력해보세요.

## 확인 퀴즈
1. 오른쪽으로 갈수록 x값은 (커진다 / 작아진다)에 동그라미 하세요.
2. 위로 갈수록 y값은 (커진다 / 작아진다)에 동그라미 하세요.
3. 블록이 실행되려면 반드시 어떤 종류의 블록 아래에 연결되어야 할까요? __________
4. `x: 0 y: 0(으)로 이동하기`와 `x좌표를 10만큼 바꾸기` 중, 누를 때마다 계속 움직이는 것은 어느 것일까요? __________
5. 컴퓨터가 알아듣는, 정확하게 정해진 명령을 무엇이라고 부를까요? __________

## 스스로 해보기
- **필수**: 방향키 4개 모두로 고양이가 사방으로 움직이게 만들고, 저장까지 마치기
- **도전 과제**: 움직이는 속도를 더 빠르게 만들어보세요. (숫자를 10 대신 몇으로 바꾸면 될까요?)
- **도전 과제 2**: 캐릭터를 하나 더 추가해서, 그 캐릭터도 똑같이 방향키로 움직이게 만들어보세요. (힌트: 캐릭터마다 따로 블록을 만들어야 해요)
- **확장 과제 (시간이 남으면)**: 배경을 바꿔보거나, 고양이 크기를 바꿔보세요.
- 시간이 부족하다면 방향키 2개만 완성해도 괜찮아요. 대신 저장은 꼭 하세요!

## 오늘의 용어 미니사전
- **무대(Stage)**: 프로그램이 실제로 실행되는 화면
- **스프라이트(Sprite)**: 무대 위에서 움직이는 등장인물(캐릭터)
- **블록 팔레트**: 사용할 수 있는 블록들이 모여있는 곳
- **스크립트(Script)**: 블록을 여러 개 이어붙여 만든 하나의 명령 묶음
- **이벤트**: "~했을 때"처럼 스크립트가 시작되는 조건
