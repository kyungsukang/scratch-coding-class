코드 (Code)

🗣️ 사람의 말

"저기 있는 거 좀 줘"
애매해도 서로 알아들어요.

VS

💻 컴퓨터의 말 = 코드

"x좌표를 10만큼 바꿔줘"
정확하게 말해야 알아들어요.

정답은 바로 '코드'예요! 사람끼리는 말이 좀 애매해도 서로 알아듣지만, 컴퓨터는 정확하게 말해주지 않으면 전혀 알아듣지 못해요. 이렇게 컴퓨터가 알아듣는 정확한 명령을 '코드'라고 부르고, 코드를 만드는 걸 '코딩'이라고 해요.

코드를 블록으로!

파이썬 같은 언어는 글자로 코드를 쓰지만,
스크래치는 블록을 끼워서 컴퓨터에게 명령을 내려요.

🏁 초록 깃발을 클릭했을 때
x좌표를 10만큼 바꾸기
그럼 코드는 어떻게 만들까요? 파이썬 같은 언어는 글자로 코드를 입력해요. 그런데 스크래치는 이 글자 코드를 직접 타이핑하지 않고, 이렇게 블록을 끼워 맞추는 것만으로 컴퓨터에게 똑같이 명령을 내릴 수 있게 해줘요.

그럼 스크래치는 진짜 코딩일까요? 정답은 '네'예요! 여기 파이썬 코드 한 줄과 스크래치 블록을 나란히 볼까요? 적는 방법(글자 vs 블록)만 다를 뿐, 컴퓨터에게 명령을 내리는 원리는 완전히 똑같아요. 오늘 우리가 블록을 조립하는 것도 진짜 코딩이에요.

스크래치 화면 구성

🖥️

무대 (Stage)

오른쪽 위 · 프로그램이 실제로 실행되는 화면

🐱

스프라이트 목록

오른쪽 아래 · 등장인물(캐릭터) 목록

🧱

블록 팔레트

왼쪽 · 카테고리별 블록 창고

🪄

스크립트 영역

가운데 · 블록을 조립하는 도마

스크래치 화면을 같이 살펴볼까요? 오른쪽 위에 있는 무대는 프로그램이 실제로 실행되는 화면이에요. 오른쪽 아래는 스프라이트, 그러니까 캐릭터 목록이고요. 왼쪽에 있는 블록 팔레트는 재료 창고 같은 곳이고, 가운데 스크립트 영역은 요리하는 도마라고 생각하면 돼요. 재료 창고에서 블록을 꺼내서 도마 위에서 조립하는 거예요.

좌표(x, y)란?

🐱
y가 커진다 ↑
y가 작아진다 ↓
x가 작아진다 ←
→ x가 커진다

가운데는 (0, 0)! 가로 -240~240, 세로 -180~180

이제 좌표를 알아볼까요? 무대는 가로로 -240부터 240까지, 세로로 -180부터 180까지예요. 가운데가 (0, 0)이고, 오른쪽으로 갈수록 x가 커지고, 위로 갈수록 y가 커져요. 수학 시간에 배운 그래프랑 똑같은 방향이에요.
다 같이 활동

좌표 맞추기 게임

"x 100, y 50으로 가보세요!"
선생님이 외치면 마우스로 고양이를 끌어서 맞혀보고, 채팅으로 완료를 알려주세요.

자, 이제 좌표 감을 잡아볼까요? 제가 "x 100, y 50으로 가보세요!" 하고 외치면, 마우스로 고양이를 끌어서 그 자리로 맞춰보세요. 다 되면 채팅으로 알려주세요. (몇 번 반복하며 좌표 감 잡기)

이동하기 vs 바꾸기

x: 0 y: 0 (으)로 이동하기

🚀 순간이동

몇 번을 눌러도 항상 같은 자리로 이동해요.

VS
x좌표를 10만큼 바꾸기

➕ 더하기

누를 때마다 지금 위치에서 계속 움직여요.

이제 중요한 블록 두 개를 비교해볼게요. 'x: 0 y: 0으로 이동하기'는 몇 번을 눌러도 항상 같은 자리로 순간이동하는 블록이에요. 반면 'x좌표를 10만큼 바꾸기'는 누를 때마다 지금 위치에서 계속 더해지면서 움직여요. 이 둘을 헷갈리면 안 돼요!

오늘 만들 스크립트

⬆️ 위쪽 화살표 키를 눌렀을 때
y좌표를 10만큼 바꾸기
⬇️ 아래쪽 화살표 키를 눌렀을 때
y좌표를 -10만큼 바꾸기
➡️ 오른쪽 화살표 키를 눌렀을 때
x좌표를 10만큼 바꾸기
⬅️ 왼쪽 화살표 키를 눌렀을 때
x좌표를 -10만큼 바꾸기
오늘 우리가 만들 스크립트는 이렇게 4개예요. 각 방향키를 눌렀을 때, 그 방향으로 좌표가 바뀌게 만드는 거예요. 지금부터 하나씩 같이 만들어볼게요.

캐릭터 되돌리기

정보 패널에서 x, y를 0, 0으로 입력해요.

블록을 다루다 보면 실수할 수도 있어요. 블록을 지우고 싶으면 팔레트 쪽으로 끌어다 놓으면 되고, 실수했으면 Ctrl+Z로 되돌릴 수 있어요. 블록을 복사하고 싶으면 우클릭해서 '복사하기'를 누르면 되고, 고양이가 화면 밖으로 사라졌으면 정보 패널에서 x, y를 0, 0으로 입력하면 돼요.

함께 만들어요!

  1. 새 프로젝트 만들기
  2. 초록 깃발 클릭했을 때 → x:0 y:0으로 이동하기
  3. 방향키 4개 스크립트 만들기
  4. 초록 깃발 눌러 실행 확인하기
  5. 저장하기
자, 이제 진짜 만들어봐요! 새 프로젝트를 만들고, 초록 깃발을 클릭했을 때 x:0 y:0으로 이동하기 블록을 연결해요. 그 다음 방향키 4개에 맞는 스크립트를 각각 만들고, 초록 깃발을 눌러서 잘 움직이는지 확인해요. 마지막으로 꼭 저장하기까지 해볼게요.

오늘 만든 것 저장하기

💾

파일 > 저장하기 / 컴퓨터에 저장하기

파일 이름: 6-2_이름_1주차

다 만들었으면 파일 메뉴에서 저장하기, 또는 컴퓨터에 저장하기를 눌러주세요. 파일 이름은 '6-2_이름_1주차' 이렇게 규칙대로 저장해주세요. (학생들 화면 하나씩 확인하며 저장 여부 체크)

스스로 해보기

필수

방향키 4개 모두 완성하고 저장까지 마치기

도전

이동 속도 더 빠르게, 캐릭터 하나 더 추가하기

확장

배경 바꾸기, 고양이 크기 바꾸기, 벽에 닿으면 시작 위치로 돌아가기

플랜B

시간이 부족하면 방향키 2개만 완성해도 OK (저장은 필수!)

이제 스스로 해볼 시간이에요. 필수는 방향키 4개를 모두 완성하고 저장까지 하는 거예요. 시간이 남으면 속도를 더 빠르게 하거나 캐릭터를 추가해보는 도전 과제도 있어요. [확장 과제 하는 법] - 배경 바꾸기: 오른쪽 아래 배경 고르기 버튼(그림 아이콘)을 클릭 → "배경 고르기" → 마음에 드는 배경을 선택해요. - 스프라이트 크기 바꾸기: 화면 위쪽 캐릭터 정보칸에서 "크기" 숫자를 바꾸면 돼요. (100이 원래 크기예요) - 벽에 닿으면 시작 위치로 돌아가기: 제어의 "무한 반복하기" 안에 "만약 <벽에 닿았는가?>라면"을 넣고, 그 안에 "x: 0 y: 0로 이동하기"를 넣으면 완성이에요. "벽에 닿았는가?"는 감지 카테고리에 있어요. (이 블록들은 다음에 자세히 배울 거라 어렵게 느껴지면 안 해도 괜찮아요!) 혹시 시간이 부족하면 방향키 2개만 완성해도 괜찮아요. 저장만 꼭 해주세요!
