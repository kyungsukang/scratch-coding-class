# 4주차 교사용 강의안 — 조건문 (if, if-else)

## 학습 목표
- "만약 ~라면" 조건문의 개념을 이해한다.
- `~에 닿았는가?` 같은 감지 블록을 조건으로 사용할 수 있다.
- `if`와 `if-else`의 차이를 알고, 상황에 맞게 사용할 수 있다.
- `forever` + `if`를 결합해 지속적으로 상황을 확인하는 프로그램을 만들 수 있다.

## 준비물
- 학생 1인당 컴퓨터/노트북 1대, 스크래치 접속

## 시간 배분 (총 60분)

| 시간 | 활동 |
|---|---|
| 0~5분 | 도입: "캐릭터가 벽에 닿아도 계속 나가버리는" 문제 보여주기 |
| 5~20분 | 개념 설명: 조건문, 감지 블록 |
| 20~45분 | 함께 실습: 벽에 닿으면 튕기기 |
| 45~55분 | 스스로 해보기 |
| 55~60분 | 정리 |

## 핵심 개념 설명 (5~20분)

**1) 조건문이란**
- "만약 ~라면, …을 한다"는 뜻. 조건이 참(True)일 때만 안에 있는 블록이 실행됨.
- 비유: "만약 비가 오면 우산을 쓴다" — 비가 안 오면 우산을 쓰지 않음.

**2) if vs if-else**
- `만약 ~라면` (if): 조건이 참일 때만 실행, 거짓이면 아무것도 안 함.
- `만약 ~라면 / 아니면` (if-else): 조건이 참이면 위쪽 실행, 거짓이면 아래쪽 실행. 항상 둘 중 하나는 실행됨.

**3) 감지 블록**
- `감지` 카테고리의 `마우스 포인터에 닿았는가?`, `벽에 닿았는가?` 등은 참/거짓 값을 반환하는 블록으로, `만약` 블록의 육각형(조건) 자리에 끼울 수 있음.

## 함께 실습 (20~45분) — 교사 진행 순서

1. `초록 깃발을 클릭했을 때` → `x: 0 y: 0(으)로 이동하기`
2. `제어`의 `계속 반복하기(forever)` 블록 연결
3. forever 안에 `동작`의 `10걸음 움직이기` 넣기
4. forever 안, 이동 블록 아래에 `만약 ~라면` 블록 추가, 조건에 `감지`의 `벽에 닿았는가?` 끼우기
5. 조건 안에 `동작`의 `180도 돌기` 넣기 (벽에 닿으면 방향을 반대로)
6. 실행해서 캐릭터가 벽에 닿을 때마다 방향을 바꾸는지 확인
7. (심화) if-else로 확장: "만약 마우스에 닿았다면 '안녕!'을 말하고, 아니면 계속 움직인다"

## 자주 발생하는 오류 & 대응 팁

| 상황 | 원인 | 해결 팁 |
|---|---|---|
| 조건 블록에 아무것도 안 끼워짐 | 육각형 홈에 안 맞는 블록을 넣으려 함 | 참/거짓을 반환하는 블록(육각형 모양)만 조건 자리에 들어간다고 설명 |
| 벽에 닿아도 반응 없음 | forever 없이 한 번만 실행됨 | forever로 감싸서 계속 확인하도록 안내 |
| 계속 제자리에서 진동함 | 180도 돌기 후 다시 바로 벽에 닿음 | 정상적인 경우가 많음, 필요하면 "만약 ~ 아니라면"으로 개선 논의 |
| if와 if-else를 혼용해 헷갈림 | 개념 미분리 | "둘 중 하나만 실행 = else 있음, 조건 안 맞으면 아무것도 안 함 = else 없음"으로 구분 설명 |
