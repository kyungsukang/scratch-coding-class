# 2주차 교사용 강의안 — 순차 실행, 모양/소리 바꾸기

## 학습 목표
- 블록이 위에서 아래로 순서대로 실행된다는 것(순차 실행)을 이해한다.
- 모양(Costume) 탭을 확인하고 `다음 모양으로 바꾸기` 블록을 사용할 수 있다.
- 소리 블록으로 효과음을 재생할 수 있다.
- 모양 바꾸기 + 기다리기 + 이동을 조합해 걷는 애니메이션을 만들 수 있다.

## 준비물
- 학생 1인당 컴퓨터/노트북 1대, 스크래치 접속: https://scratch.mit.edu/projects/editor/
- 1주차에 만든 프로젝트 (있으면 이어서 사용, 없으면 새로 시작)

## 시간 배분 (총 60분)

| 시간 | 활동 |
|---|---|
| 0~5분 | 도입: 1주차 복습(방향키 이동) + 오늘 목표(캐릭터가 걷는 것처럼 보이게 하기) |
| 5~20분 | 개념 설명: 순차 실행, 모양탭, 소리탭 |
| 20~45분 | 함께 실습 |
| 45~55분 | 스스로 해보기 |
| 55~60분 | 정리 |

## 핵심 개념 설명 (5~20분)

**1) 순차 실행**
- 블록은 항상 위에서 아래로, 하나씩 순서대로 실행된다.
- 비유: "양말을 신고 신발을 신어야지, 신발을 신고 양말을 신으면 이상하죠?" — 순서를 바꾸면 결과가 달라진다.

**2) 모양(Costume) 탭**
- 스프라이트 영역 위쪽 "모양" 탭을 클릭하면 캐릭터가 가진 여러 모습(모양1, 모양2 …)을 볼 수 있다.
- `형태` 카테고리의 `다음 모양으로 바꾸기` 블록으로 순서대로 전환된다.

**3) 소리(Sound) 탭**
- "소리" 탭에서 사용 가능한 효과음을 확인한다.
- `소리` 카테고리의 `재생하기` 블록으로 소리를 낼 수 있다.

## 함께 실습 (20~45분) — 교사 진행 순서

1. 1주차 프로젝트 열기(또는 새로 시작)
2. "모양" 탭 클릭 → 고양이가 모양1, 모양2 두 가지를 가진 것 확인
3. `오른쪽 화살표 키를 눌렀을 때` 스크립트에 아래 순서로 블록 연결:
   - `다음 모양으로 바꾸기`
   - `x좌표를 10만큼 바꾸기`
4. 실행해서 걷는 것처럼 보이는지 확인 (모양이 바뀌지 않으면 다음 단계로)
5. 같은 방식으로 왼쪽/위/아래 화살표 스크립트에도 `다음 모양으로 바꾸기` 추가
6. `스페이스 키를 눌렀을 때` → `소리` 카테고리에서 `야옹 재생하기` 블록 연결

## 자주 발생하는 오류 & 대응 팁

| 상황 | 원인 | 해결 팁 |
|---|---|---|
| 모양이 안 바뀜 | 스프라이트에 모양이 1개뿐 | 모양 탭에서 모양 개수 확인, 없으면 다른 스프라이트로 시도 |
| 너무 빨리 바뀌어 안 보임 | 실제로는 잘 작동 중 (사람 눈에 빠름) | 정상 동작임을 설명, 원하면 `0.1초 기다리기` 추가해 속도 조절 가능하다고 안내 |
| 소리가 안 남 | 소리 탭에 소리가 없거나 볼륨 문제 | 소리 탭에서 기본 효과음 추가하는 법 안내, 컴퓨터 볼륨 확인 |
| 순서를 바꿔도 똑같아 보임 | 블록 2개가 서로 영향 없는 경우라 순서 상관없음 | 극단적 예시(먼저 크게 움직이고 나중에 모양 바꾸기 vs 반대)로 실험시켜 차이 체감시키기 |
