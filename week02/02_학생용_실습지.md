# 2주차 실습지 — 걷는 애니메이션 만들기

이름: ______________

## 오늘의 미션
방향키를 누르면 고양이가 진짜로 "걷는 것처럼" 보이게 만들어봅시다!

## 준비하기
1주차에 만든 프로젝트를 열거나, 없다면 새 프로젝트를 시작하세요.

## 단계별로 따라하기

**1단계. 모양 확인하기**
- 스프라이트 영역 위쪽 "모양" 탭을 클릭하세요.
- 고양이 캐릭터가 모양을 몇 개 가지고 있나요? __________

**2단계. 모양 바뀌는 것 관찰하기**
- `이벤트` 카테고리에서 `스페이스 키를 눌렀을 때` 블록을 새로 놓으세요.
- `형태` 카테고리에서 `다음 모양으로 바꾸기` 블록을 연결하세요.
- 스페이스 키를 여러 번 눌러보고, 고양이 모양이 바뀌는 걸 관찰하세요.

**3단계. 걷기 애니메이션 만들기**
`오른쪽 화살표 키를 눌렀을 때` 스크립트를 아래 순서로 만드세요.

| 순서 | 블록 |
|---|---|
| 1 | 다음 모양으로 바꾸기 |
| 2 | x좌표를 10만큼 바꾸기 |

- 실행(초록 깃발)해서 오른쪽 화살표를 눌러보고, 걷는 것처럼 보이는지 확인하세요.

**4단계. 소리 추가하기**
- `이벤트`에서 `스페이스 키를 눌렀을 때` 블록을 새로 만들고, `소리` 카테고리에서 소리 재생 블록을 연결하세요.

2. 순서를 바꾸면 결과가 달라질 수 있는 이유를 한 문장으로 써보세요.

2. `0.1초 기다리기` 블록을 중간에 넣어보고, 애니메이션 속도가 어떻게 달라지는지 확인해보세요.
