# 9주차 교사용 강의안 — 중첩 조건문, 가위바위보 게임

## 학습 목표
- 조건문 안에 또 다른 조건문을 넣는 "중첩(nested)" 구조를 이해한다.
- 여러 경우의 수를 빠짐없이 나누어 처리하는 법을 익힌다.
- 지금까지 배운 변수, 난수, 조건문을 종합해 가위바위보 게임을 만들 수 있다.

## 준비물
- 학생 1인당 컴퓨터/노트북 1대, 스크래치 접속

## 시간 배분 (총 60분)

| 시간 | 활동 |
|---|---|
| 0~5분 | 도입: 실제로 가위바위보 한 판 하고 승패 규칙 복습 |
| 5~20분 | 개념 설명: 중첩 조건문, 경우의 수 정리 |
| 20~45분 | 함께 실습: 가위바위보 게임 |
| 45~55분 | 스스로 해보기 |
| 55~60분 | 정리 |

## 핵심 개념 설명 (5~20분)

**1) 중첩 조건문이란**
- `만약 ~라면` 블록 안에 또 `만약 ~라면` 블록을 넣는 것.
- 비유: "만약 오늘 학교에 간다면 → (그 안에서) 만약 비가 온다면 우산을 챙긴다"

**2) 경우의 수를 정리하는 법**
- 가위바위보는 (내 선택, 컴퓨터 선택) 조합이 3×3=9가지지만, 다음과 같이 단순화 가능:
  - 같으면 → 비김
  - 내가 가위인데 컴퓨터가 보 → 이김 / 컴퓨터가 바위 → 짐
  - 내가 바위인데 컴퓨터가 가위 → 이김 / 컴퓨터가 보 → 짐
  - 내가 보인데 컴퓨터가 바위 → 이김 / 컴퓨터가 가위 → 짐
- 표로 미리 정리해서 칠판에 적어두고 시작하면 학생들이 훨씬 수월하게 따라옴.

## 함께 실습 (20~45분) — 교사 진행 순서

1. 변수 "내선택", "컴퓨터선택" 만들기
2. `초록 깃발을 클릭했을 때` → `컴퓨터선택을 (1부터 3사이의 난수)로 정하기` (1=가위, 2=바위, 3=보로 약속)
3. `(가위(1), 바위(2), 보(3) 중 골라 숫자를 입력하세요)라고 묻고 기다리기` → `내선택을 대답으로 정하기`
4. `만약 ~라면 / 아니면` 중첩 구조로 승패 판정:
   - 바깥 if: `내선택 = 컴퓨터선택` → "비겼습니다"
   - else 안에 또 if: `(내선택=1 그리고 컴퓨터선택=3) 또는 (내선택=2 그리고 컴퓨터선택=1) 또는 (내선택=3 그리고 컴퓨터선택=2)` → "이겼습니다" / 아니면 "졌습니다"
   - (연산자의 "그리고", "또는" 블록 이번 시간에 함께 소개)
5. 실행해서 여러 번 테스트하며 모든 경우가 맞는지 확인

## 자주 발생하는 오류 & 대응 팁

| 상황 | 원인 | 해결 팁 |
|---|---|---|
| 특정 조합에서만 결과가 이상함 | 경우의 수를 빠뜨림 | 표로 9가지 경우를 하나씩 짚으며 확인 |
| "그리고"/"또는" 블록을 헷갈려함 | 논리 연산자 개념 생소 | "그리고=둘 다 참이어야 함", "또는=하나만 참이어도 됨"으로 구분 설명 |
| if가 너무 많아 복잡해함 | 중첩 구조 익숙하지 않음 | 바깥 조건(비김)부터 먼저 해결하고, 나머지 안에서 나누라고 단계적으로 안내 |
| 컴퓨터선택이 안 바뀜 | 초기화 위치나 난수 재설정 시점 문제 | 초록 깃발 클릭 시마다 새로 뽑히는지 확인 |
