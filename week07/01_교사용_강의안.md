# 7주차 교사용 강의안 — 이벤트/신호(Broadcast)

## 학습 목표
- 신호(메시지)를 만들고 보낼 수 있다.
- `신호를 받았을 때` 블록으로 다른 스프라이트의 동작을 시작시킬 수 있다.
- `신호 보내기`와 `신호를 보내고 기다리기`의 차이를 안다.
- 여러 캐릭터가 순서대로(릴레이처럼) 동작하는 프로그램을 만들 수 있다.

## 준비물
- 학생 1인당 컴퓨터/노트북 1대, 스크래치 접속
- 스프라이트 2개 이상 필요 (기본 제공 스프라이트 추가로 사용)

## 시간 배분 (총 60분)

| 시간 | 활동 |
|---|---|
| 0~5분 | 도입: "이어달리기"처럼 순서대로 신호를 주고받는 비유 소개 |
| 5~20분 | 개념 설명: 신호 만들기/보내기/받기 |
| 20~45분 | 함께 실습: 캐릭터 릴레이 동작 |
| 45~55분 | 스스로 해보기 |
| 55~60분 | 정리 |

## 핵심 개념 설명 (5~20분)

**1) 신호(메시지)란**
- 한 캐릭터가 "이제 네 차례야!"라고 다른 캐릭터에게 알려주는 방법.
- 비유: 이어달리기에서 바통을 넘겨주는 것과 같음.

**2) 신호 관련 블록**
- `이벤트`의 `새로운 메시지` → 신호 이름 만들기(예: "시작해")
- `(시작해) 신호 보내기`: 신호를 보내고 바로 다음 블록 실행 (기다리지 않음)
- `(시작해) 신호를 보내고 기다리기`: 신호를 받은 쪽의 동작이 끝날 때까지 기다렸다가 다음 블록 실행
- `(시작해) 신호를 받았을 때`: 이 신호를 받으면 아래 블록들을 실행

**3) 신호가 필요한 이유**
- 스프라이트끼리는 서로의 스크립트를 직접 실행시킬 수 없음 → 신호로 "지금 실행해!"라고 알려줘야 함.

## 함께 실습 (20~45분) — 교사 진행 순서

1. 스프라이트 2개 준비 (예: 고양이, 강아지)
2. `이벤트`에서 `새로운 메시지` 클릭 → 이름 "시작해"로 생성
3. 고양이: `초록 깃발을 클릭했을 때` → "안녕!"이라고 2초 동안 말하기 → `(시작해) 신호 보내기`
4. 강아지: `(시작해) 신호를 받았을 때` → "나도 안녕!"이라고 2초 동안 말하기
5. 실행해서 고양이가 먼저 말하고, 이어서 강아지가 말하는지 확인
6. `신호 보내기`를 `신호를 보내고 기다리기`로 바꿔서 차이 비교 (겹쳐 말하는지 vs 순서대로 말하는지)

## 자주 발생하는 오류 & 대응 팁

| 상황 | 원인 | 해결 팁 |
|---|---|---|
| 신호를 보내도 반응 없음 | 다른 스프라이트에 `신호를 받았을 때` 블록이 없음 | 신호는 "받는 스크립트"가 있어야 동작한다고 설명 |
| 신호 이름이 여러 개라 헷갈림 | 신호를 여러 개 만들고 이름을 비슷하게 지음 | 신호 이름을 목적이 드러나게 짓기(예: "게임시작", "게임종료") |
| 두 캐릭터가 동시에 말해서 겹침 | `신호 보내기`(안 기다림) 사용 | `신호를 보내고 기다리기`로 바꾸면 순서대로 진행됨을 보여주기 |
| 신호를 보냈는데 한 번만 반응함 | forever 없이 한 번만 받게 되어 있음 | 의도한 동작인지 확인, 반복이 필요하면 forever 추가 |
