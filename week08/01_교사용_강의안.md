# 8주차 교사용 강의안 — 리스트(배열) 기초

## 학습 목표
- 리스트가 "여러 칸을 가진 상자"라는 개념을 이해한다.
- 리스트를 만들고, 항목을 추가/삭제할 수 있다.
- 리스트의 길이(항목 개수)와 순서(1번부터 시작)를 이해한다.
- 반복문과 리스트를 결합해 전체 항목을 출력할 수 있다.

## 준비물
- 학생 1인당 컴퓨터/노트북 1대, 스크래치 접속

## 시간 배분 (총 60분)

| 시간 | 활동 |
|---|---|
| 0~5분 | 도입: "변수 상자 하나로 여러 명의 이름을 저장할 수 있을까?" 질문 |
| 5~20분 | 개념 설명: 리스트, 추가/삭제, 인덱스 |
| 20~45분 | 함께 실습: 출석부 만들기 |
| 45~55분 | 스스로 해보기 |
| 55~60분 | 정리 |

## 핵심 개념 설명 (5~20분)

**1) 리스트란**
- 변수는 상자 1칸, 리스트는 칸이 여러 개인 서랍장과 같음. 여러 개의 값을 순서대로 저장할 수 있음.

**2) 리스트 만들기**
- `변수` 카테고리 → `리스트 만들기` → 이름 입력(예: "출석부")

**3) 주요 블록**
- `( )을 (리스트)에 추가하기`: 맨 뒤에 항목 추가
- `(리스트)의 ( )번째 항목을 삭제하기`, `(리스트)의 모든 항목을 삭제하기`
- `(리스트)의 길이`: 항목이 몇 개 있는지
- `(리스트)의 ( )번째 항목`: 특정 순서의 값 가져오기

**4) ⚠️ 중요: 순서는 1부터 시작**
- 프로그래밍 언어 중에는 0부터 시작하는 경우도 있지만, 스크래치 리스트는 1번째부터 시작한다는 것을 명확히 짚어줄 것.

## 함께 실습 (20~45분) — 교사 진행 순서

1. `리스트 만들기`로 "출석부" 생성
2. `초록 깃발을 클릭했을 때` → `출석부의 모든 항목을 삭제하기` (초기화)
3. `(이름이 뭐예요?)라고 묻고 기다리기` → `대답을 출석부에 추가하기`
4. `스페이스 키를 눌렀을 때` → `제어`의 `반복하기(출석부의 길이)` → 안에 `(출석부의 (i)번째 항목)을 2초 동안 말하기` — 이때 `i`는 반복 인덱스를 위한 변수 하나 추가로 만들어 활용(또는 간단히 "모두 말하기"로 대체 가능)
5. 실행해서 이름을 여러 번 입력받고, 스페이스로 전체 출석부를 순서대로 말하는지 확인

## 자주 발생하는 오류 & 대응 팁

| 상황 | 원인 | 해결 팁 |
|---|---|---|
| 항목이 계속 쌓임 | 초록 깃발 시 삭제를 안 함 | `모든 항목을 삭제하기`를 초기화 스크립트에 넣기 |
| 몇 번째 항목인지 헷갈림 | 0번째로 착각 | 리스트는 1번째부터 시작한다고 반복 강조 |
| 반복하기 안에서 항목이 안 바뀜 | 인덱스를 나타내는 변수를 사용하지 않음 | 별도의 "번호" 변수를 만들어 1씩 증가시키며 사용하는 방법 안내 (또는 심화 학생만 도전) |
| 리스트가 무대에 안 보임 | 체크박스 꺼짐 | 블록 팔레트에서 리스트 이름 옆 체크박스 확인 |
