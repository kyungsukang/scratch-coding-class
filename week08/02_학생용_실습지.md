# 8주차 실습지 — 리스트로 출석부 만들기

이름: ______________

## 오늘의 미션
친구들의 이름을 입력받아 저장하고, 전체 목록을 보여주는 출석부를 만들어봅시다!

## 단계별로 따라하기

**1단계. 리스트 만들기**
- `변수` 카테고리에서 `리스트 만들기`를 클릭하고 이름을 **"출석부"**로 만드세요.

**2단계. 시작할 때 비우기**
- `초록 깃발을 클릭했을 때` → `출석부의 모든 항목을 삭제하기`를 연결하세요.

**3단계. 이름 입력받아 추가하기**
- 같은 스크립트에 `(이름이 뭐예요?)라고 묻고 기다리기`를 연결하세요.
- 그 아래에 `대답을 출석부에 추가하기`를 연결하세요.

**4단계. 실행하고 여러 번 입력하기**
- 초록 깃발을 눌러 이름을 하나 입력해보세요.
- 무대에 나타난 "출석부" 리스트에 이름이 추가됐는지 확인하세요.
- 다시 스크립트를 클릭해서 이름을 2~3개 더 추가해보세요.
