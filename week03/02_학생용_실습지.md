이름: ______________

## 오늘의 미션
반복문과 펜을 이용해 정사각형, 정삼각형, 그리고 나만의 다각형을 그려봅시다!

## 준비하기
1. 화면 왼쪽 아래 "확장 기능 추가" 버튼을 클릭하세요.
2. "펜(Pen)"을 선택해서 추가하세요.

## 단계별로 따라하기

**1단계. 기본 준비 스크립트 만들기**
- `초록 깃발을 클릭했을 때` → `모두 지우기` → `펜 내리기` 순서로 블록을 연결하세요.

**2단계. 정사각형 그리기**
- `제어` 카테고리의 `repeat( )번 반복하기` 블록을 연결하고, 숫자를 **4**로 바꾸세요.
- 반복 블록 안에 아래 2개를 순서대로 넣으세요.
  - `10걸음 움직이기` (숫자를 100 정도로 바꿔도 좋아요)
  - `90도 돌기`
- 실행해서 정사각형이 그려지는지 확인하세요.

**3단계. 정삼각형 그리기**
- repeat 숫자를 **3**으로, 회전 각도를 **120**으로 바꿔보세요.
- 실행 결과를 확인하세요.

**4단계. 규칙 찾기**
아래 표를 채우면서 규칙을 찾아보세요. (360을 반복 횟수로 나눈 값이 회전 각도예요!)

| 도형 | 반복 횟수 | 회전 각도 (360 ÷ 반복 횟수) |
|---|---|---|
| 정사각형 | 4 | |
| 정삼각형 | 3 | |
