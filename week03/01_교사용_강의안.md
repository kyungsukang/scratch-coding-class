# 3주차 교사용 강의안 — 반복문 (repeat, forever)

## 학습 목표
- 반복문이 왜 필요한지(같은 블록을 여러 번 안 써도 됨) 이해한다.
- `repeat(반복하기)`와 `forever(계속 반복하기)`의 차이를 안다.
- 펜(Pen) 확장 기능으로 도형을 그릴 수 있다.
- 반복 횟수와 회전 각도의 관계를 이용해 다양한 도형을 그릴 수 있다.

## 준비물
- 학생 1인당 컴퓨터/노트북 1대, 스크래치 접속
- 확장 기능 "펜(Pen)" 추가 필요 (화면 왼쪽 아래 확장 기능 추가 버튼)

## 시간 배분 (총 60분)

| 시간 | 활동 |
|---|---|
| 0~5분 | 도입: 지난주 복습 + "이걸 100번 반복해야 한다면?" 문제 제기 |
| 5~20분 | 개념 설명: 반복문, 펜 확장기능 |
| 20~45분 | 함께 실습: 사각형 → 다각형 그리기 |
| 45~55분 | 스스로 해보기 |
| 55~60분 | 정리 |

## 핵심 개념 설명 (5~20분)

**1) 반복문이 필요한 이유**
- 2주차에 만든 애니메이션처럼 같은 동작을 여러 번 하려면 블록을 계속 복사해야 해서 불편함.
- `제어` 카테고리의 `repeat(10)번 반복하기` 블록 안에 넣으면 10번 반복 실행됨.
- `forever(계속 반복하기)`는 멈추라고 할 때까지(또는 프로그램이 꺼질 때까지) 무한 반복.

**2) 펜 확장 기능**
- 화면 왼쪽 아래 "확장 기능 추가" (파란 + 버튼) 클릭 → "펜" 선택
- `펜 내리기` = 그리기 시작, `펜 올리기` = 그리기 멈춤, `모두 지우기` = 그림 지우기

**3) 도형 그리기 원리**
- 정사각형 = "앞으로 이동 + 90도 회전"을 4번 반복
- 정삼각형 = "앞으로 이동 + 120도 회전"을 3번 반복
- 규칙: 정N각형은 (360 ÷ N)도씩 회전하며 N번 반복

## 함께 실습 (20~45분) — 교사 진행 순서

1. 확장 기능에서 "펜" 추가
2. 새 스크립트: `초록 깃발을 클릭했을 때` → `모두 지우기` → `펜 내리기`
3. `제어`의 `repeat(4)번 반복하기` 블록 연결, 안에 `동작`의 `10걸음 움직이기`, `90도 돌기`를 순서대로 넣기
4. 실행 → 정사각형이 그려지는지 확인
5. `repeat`를 3, `90도 돌기`를 120도로 바꿔서 삼각형 만들어보기
6. 규칙(360÷N) 함께 계산해서 정오각형(5, 72도), 정육각형(6, 60도)도 시도

## 자주 발생하는 오류 & 대응 팁

| 상황 | 원인 | 해결 팁 |
|---|---|---|
| 도형이 안 그려짐 | 펜 내리기를 빼먹음 | `펜 내리기` 블록이 있는지 확인 |
| 도형이 안 닫힘(어긋남) | 회전 각도 계산 실수 | 360÷반복횟수 공식을 함께 계산해보기 |
| 이전 그림이 겹쳐 보임 | `모두 지우기`를 안 함 | 실행 전 항상 `모두 지우기` 넣도록 습관화 |
| repeat와 forever를 헷갈림 | 개념 혼동 | "정해진 횟수 = repeat, 끝없이 = forever"로 반복해서 짚어주기 |
