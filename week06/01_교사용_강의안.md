# 6주차 교사용 강의안 — 변수 응용 + 연산자, 랜덤 숫자 맞추기 게임

## 학습 목표
- 무작위 수(난수) 블록을 사용할 수 있다.
- 비교 연산자(=, <, >)로 두 값을 비교할 수 있다.
- `묻고 기다리기` 블록으로 사용자 입력을 받고, `대답` 변수를 활용할 수 있다.
- 변수 + 연산자 + 조건문을 결합해 숫자 맞추기 게임을 만들 수 있다.

## 준비물
- 학생 1인당 컴퓨터/노트북 1대, 스크래치 접속

## 시간 배분 (총 60분)

| 시간 | 활동 |
|---|---|
| 0~5분 | 도입: "1~10 사이 숫자를 맞춰보세요!" 즉석 퀴즈로 흥미 유발 |
| 5~20분 | 개념 설명: 난수, 연산자, 묻고 기다리기 |
| 20~45분 | 함께 실습: 숫자 맞추기 게임 |
| 45~55분 | 스스로 해보기 |
| 55~60분 | 정리 |

## 핵심 개념 설명 (5~20분)

**1) 무작위 수(난수) 블록**
- `연산자` 카테고리의 `(1)부터 (10)사이의 난수` 블록은 실행할 때마다 그 범위 안에서 무작위 숫자를 뽑아줌.

**2) 비교 연산자**
- `연산자`의 `( ) = ( )`, `( ) < ( )`, `( ) > ( )` 블록은 참/거짓을 반환하는 육각형 블록으로, `만약` 블록 조건 자리에 사용 가능.

**3) 묻고 기다리기 & 대답**
- `감지`의 `( )라고 묻고 기다리기` 블록은 화면 아래 입력창을 띄우고, 학생이 입력한 값을 `대답` 변수에 자동으로 저장함.
- ⚠️ `대답`은 가장 최근 질문의 답만 저장하므로, 값을 쓰려면 질문 직후에 사용해야 함.

## 함께 실습 (20~45분) — 교사 진행 순서

1. `변수 만들기`로 "정답" 변수 생성
2. `초록 깃발을 클릭했을 때` → `정답을 (1부터 10사이의 난수)로 정하기`
3. 같은 스크립트에 `(숫자를 맞춰보세요!)라고 묻고 기다리기` 연결
4. `만약 ~라면 / 아니면` 블록 연결, 조건에 `대답 = 정답` 끼우기
5. 조건이 참일 때: `정답이에요!`라고 말하기 / 거짓일 때: `틀렸어요. 정답은 (정답)이었어요`라고 말하기 (연산자 블록으로 문자 합치기 소개)
6. 실행해서 여러 번 테스트

## 자주 발생하는 오류 & 대응 팁

| 상황 | 원인 | 해결 팁 |
|---|---|---|
| 항상 틀렸다고 나옴 | `대답`이 텍스트라서 숫자 비교가 안 맞는 경우 | 스크래치는 자동 변환해주므로 보통 문제없음, 안 되면 정답 변수를 다시 확인 |
| 매번 같은 정답이 나옴 | 난수를 초록 깃발 클릭 시가 아니라 게임 도중 한 번만 뽑음 | 초기화 스크립트 위치 확인 |
| 질문이 안 뜸 | `묻고 기다리기` 블록이 다른 스크립트에 있음 | 같은 스크립트 흐름 안에 있는지 확인 |
| 대답 값이 이상함 | 다른 질문 이후에 대답을 사용해서 값이 덮어써짐 | "대답은 가장 최근 질문 결과"라는 점을 다시 설명 |
