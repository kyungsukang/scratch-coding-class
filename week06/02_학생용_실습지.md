# 6주차 실습지 — 랜덤 숫자 맞추기 게임

이름: ______________

## 오늘의 미션
컴퓨터가 1~10 사이에서 정한 숫자를 맞추는 게임을 만들어봅시다!

## 단계별로 따라하기

**1단계. 변수 만들기**
- `변수 만들기`로 "정답"이라는 변수를 만드세요.

**2단계. 정답 정하기**
- `초록 깃발을 클릭했을 때` 블록 아래에 `연산자` 카테고리의 `(1부터 10사이의 난수)` 블록을 `정답을 ( )로 정하기`의 빈칸에 끼우세요.

**3단계. 질문하기**
- 같은 스크립트에 `감지` 카테고리의 `(숫자를 맞춰보세요!)라고 묻고 기다리기` 블록을 연결하세요.

**4단계. 정답 확인하기**
- `제어`의 `만약 ~라면 / 아니면` 블록을 연결하세요.
- 조건 자리에 `연산자`의 `( ) = ( )` 블록을 끼우고, 양쪽에 `감지`의 `대답`과 변수 `정답`을 각각 넣으세요.
- 조건이 맞을 때: "정답이에요!"라고 말하기
- 조건이 틀릴 때: "틀렸어요"라고 말하기

**5단계. 실행하고 테스트하기**
- 여러 번 실행해서 정답을 맞혀보고, 틀린 경우도 확인해보세요.

## 확인 퀴즈
1. `대답` 변수에는 어떤 값이 저장되나요? __________
2. `(1부터 10사이의 난수)` 블록을 실행할 때마다 값이 똑같을까요, 다를까요? __________

## 스스로 해보기 (도전 과제)
1. 틀렸을 때 "틀렸어요. 정답은 [정답]이었어요"처럼 정답도 함께 알려주도록 만들어보세요. (힌트: 연산자의 "문자 합치기" 블록 사용)
2. 시도 횟수를 세는 변수를 추가해서, 몇 번 만에 맞췄는지 보여주도록 만들어보세요.
