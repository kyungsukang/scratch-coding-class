# 5주차 교사용 강의안 — 변수 개념

## 학습 목표
- 변수가 "값을 기억하는 상자"라는 개념을 이해한다.
- 변수를 직접 만들고, 초기화(0으로 정하기)할 수 있다.
- 변수 값을 바꾸는 블록(~만큼 바꾸기, ~로 정하기)의 차이를 안다.
- 변수를 이용해 점수 카운터를 만들 수 있다.

## 준비물
- 학생 1인당 컴퓨터/노트북 1대, 스크래치 접속

## 시간 배분 (총 60분)

| 시간 | 활동 |
|---|---|
| 0~5분 | 도입: "게임 점수는 어떻게 기억될까?" 질문 던지기 |
| 5~20분 | 개념 설명: 변수, 초기화, 값 바꾸기 |
| 20~45분 | 함께 실습: 점수 카운터 만들기 |
| 45~55분 | 스스로 해보기 |
| 55~60분 | 정리 |

## 핵심 개념 설명 (5~20분)

**1) 변수란**
- 변수는 값을 담아두는 "상자"와 같음. 상자에 이름표(변수명)를 붙이고, 안에 숫자나 글자를 넣을 수 있음.
- 예: "점수"라는 상자를 만들면, 그 안에 0, 1, 2… 같은 숫자를 넣었다 뺐다 할 수 있음.

**2) 변수 만들기**
- `변수` 카테고리 → `변수 만들기` 클릭 → 이름 입력(예: "점수") → 확인
- 무대에 변수 값이 자동으로 표시됨 (체크박스로 켜고 끌 수 있음)

**3) 값 바꾸기 vs 정하기**
- `변수를 (0)로 정하기`: 값을 완전히 새로운 값으로 덮어씀 (초기화할 때 사용)
- `변수를 (1)만큼 바꾸기`: 기존 값에 더하거나 뺌 (증가/감소시킬 때 사용)

**4) 왜 초기화가 중요한가**
- 초록 깃발을 다시 눌러도 이전 점수가 남아있으면 안 되므로, 시작할 때 항상 "0으로 정하기"를 해줘야 함.

## 함께 실습 (20~45분) — 교사 진행 순서

1. `변수` 카테고리에서 `변수 만들기` → 이름 "점수"로 생성
2. `초록 깃발을 클릭했을 때` → `점수를 0로 정하기` (초기화)
3. `스페이스 키를 눌렀을 때` → `점수를 1만큼 바꾸기`
4. 실행해서 스페이스를 누를 때마다 무대의 점수가 올라가는지 확인
5. 초록 깃발을 다시 눌러서 점수가 0으로 초기화되는지 확인
6. (심화) 다른 키(예: "a 키를 눌렀을 때")로 `점수를 -1만큼 바꾸기` 추가해서 감점 기능도 만들기

## 자주 발생하는 오류 & 대응 팁

| 상황 | 원인 | 해결 팁 |
|---|---|---|
| 점수가 계속 이전 값에서 시작함 | 초기화(0으로 정하기)를 안 함 | 초록 깃발 스크립트에 초기화 블록이 있는지 확인 |
| 점수가 안 올라감 | "~로 정하기"를 써서 항상 같은 값으로 덮어씀 | "~만큼 바꾸기"와의 차이를 다시 설명 |
| 무대에 점수가 안 보임 | 변수 체크박스가 꺼져 있음 | 블록 팔레트에서 변수 이름 옆 체크박스 확인 |
| 변수 이름을 헷갈려함 | 여러 변수를 만들면서 혼동 | 변수 이름을 명확하게(예: "점수", "생명") 짓는 습관 강조 |
