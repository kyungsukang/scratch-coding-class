# 5주차 실습지 — 점수 카운터 만들기

이름: ______________

## 오늘의 미션
스페이스 키를 누를 때마다 점수가 올라가는 프로그램을 만들어봅시다!

## 단계별로 따라하기

**1단계. 변수 만들기**
- `변수` 카테고리에서 `변수 만들기`를 클릭하세요.
- 이름을 **"점수"**라고 입력하고 확인을 누르세요.
- 무대 화면에 점수 상자가 나타나는지 확인하세요.

**2단계. 시작할 때 점수 초기화하기**
- `초록 깃발을 클릭했을 때` 블록을 놓으세요.
- `변수` 카테고리에서 `점수를 0로 정하기` 블록을 연결하세요.

**3단계. 키를 누르면 점수 올리기**
- `이벤트`에서 `스페이스 키를 눌렀을 때` 블록을 새로 놓으세요.
- `변수`에서 `점수를 1만큼 바꾸기` 블록을 연결하세요.

**4단계. 실행하고 확인하기**
- 초록 깃발을 누르고, 스페이스를 여러 번 눌러 점수가 올라가는지 확인하세요.
- 초록 깃발을 다시 눌러서 점수가 0으로 돌아가는지도 확인하세요.
