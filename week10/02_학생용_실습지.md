# 10주차 실습지 — 나만의 블록으로 정다각형 그리기

이름: ______________

## 오늘의 미션
숫자만 바꾸면 어떤 정다각형이든 그릴 수 있는 "나만의 블록"을 만들어봅시다!

## 단계별로 따라하기

**1단계. 블록 만들기**
- `내 블록` 카테고리에서 `블록 만들기`를 클릭하세요.
- 이름을 **"정다각형 그리기"**로 입력하세요.
- "숫자 또는 텍스트 입력값 추가"를 눌러서 이름을 **"변의 개수"**로 추가하세요.

**2단계. 블록 내용 만들기**
- 새로 생긴 `정다각형 그리기 (변의 개수)` 정의 블록 아래에 연결하세요.
  - `펜 내리기`
  - `repeat(변의 개수)번 반복하기` 안에:
    - `10걸음 움직이기`
    - `(360 ÷ 변의 개수)도 돌기` (연산자의 나누기 블록을 사용하고, 매개변수 "변의 개수"를 끼우세요)

**3단계. 블록 사용하기**
- `초록 깃발을 클릭했을 때` → `모두 지우기` → `정다각형 그리기 (4)` 블록을 연결해서 호출하세요.
- 실행해서 정사각형이 그려지는지 확인하세요.
- 숫자를 6, 8, 10으로 바꿔서 각각 실행해보세요.
