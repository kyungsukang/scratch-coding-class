# 10주차 교사용 강의안 — 나만의 블록(함수)

## 학습 목표
- "나만의 블록"(사용자 정의 함수)이 왜 필요한지 이해한다.
- 나만의 블록을 만들고 호출할 수 있다.
- 매개변수(입력값)를 추가해 블록을 더 유연하게 만들 수 있다.
- 이전에 만든 반복 코드를 나만의 블록으로 리팩토링(정리)할 수 있다.

## 준비물
- 학생 1인당 컴퓨터/노트북 1대, 스크래치 접속
- 3주차에 만든 "도형 그리기" 프로젝트 (있으면 재사용, 없으면 새로 간단히 만들기)

## 시간 배분 (총 60분)

| 시간 | 활동 |
|---|---|
| 0~5분 | 도입: "정사각형, 삼각형, 오각형 코드를 각각 다 만들면?" 불편함 제기 |
| 5~20분 | 개념 설명: 나만의 블록, 매개변수 |
| 20~45분 | 함께 실습: 정다각형 그리기 블록 만들기 |
| 45~55분 | 스스로 해보기 |
| 55~60분 | 정리 |

## 핵심 개념 설명 (5~20분)

**1) 나만의 블록이 필요한 이유**
- 3주차에서 정사각형, 정삼각형을 그릴 때마다 반복 블록을 새로 만들어야 했음.
- 반복해서 쓰는 코드 덩어리를 "블록 하나"로 묶어두면, 필요할 때마다 그 블록만 불러 쓰면 됨.

**2) 나만의 블록 만들기**
- `내 블록` 카테고리 → `블록 만들기` → 이름 입력(예: "정다각형 그리기")
- 만들어진 정의 블록 아래에 실제 동작(반복문 등)을 조립

**3) 매개변수(입력값)**
- 블록 만들기 창에서 "숫자 또는 텍스트 입력값 추가"를 누르면, 블록을 쓸 때마다 다른 값을 넣을 수 있음.
- 예: "정다각형 그리기 (변의 개수)" → 변의 개수에 4를 넣으면 정사각형, 5를 넣으면 정오각형

## 함께 실습 (20~45분) — 교사 진행 순서

1. `내 블록`에서 `블록 만들기` → 이름 "정다각형 그리기"
2. "숫자 입력값 추가" 클릭 → 이름 "변의 개수"로 매개변수 추가
3. 정의 블록 아래에 3주차 코드를 옮겨오기:
   - `repeat(변의 개수)번 반복하기` 안에 `10걸음 움직이기`, `(360 ÷ 변의 개수)도 돌기`
   - 이때 "360÷변의 개수"는 `연산자`의 나누기 블록에 매개변수를 끼워 넣어 자동 계산되게 함
4. 원래 스크립트로 돌아가서 `초록 깃발을 클릭했을 때` 아래에 `정다각형 그리기 (4)` 블록 호출 → 실행 확인
5. 숫자만 바꿔서 `정다각형 그리기 (6)`, `정다각형 그리기 (10)`도 호출해보기

## 자주 발생하는 오류 & 대응 팁

| 상황 | 원인 | 해결 팁 |
|---|---|---|
| 매개변수를 안 쓰고 숫자를 직접 씀 | 매개변수 개념이 아직 낯섦 | "숫자가 바뀔 수 있는 자리에는 매개변수를 쓴다"고 예시로 설명 |
| 블록 정의와 호출을 헷갈림 | 두 군데(정의부/호출부)가 따로 있다는 것을 모름 | "블록 만들기 = 레시피 적기, 블록 호출 = 요리 시키기"로 비유 |
| 각도 계산이 이상함 | 360÷변의개수 대신 고정값을 사용 | 연산자 블록으로 자동 계산하도록 다시 안내 |
| 실행해도 그림이 안 그려짐 | 펜 관련 블록(펜 내리기 등)이 빠짐 | 3주차 내용 복습 연결 |
